Now / Learning

Studying for CompTIA Network+.

Alongside it I'm working through the gap between "I built this once" and "I could run this for someone else." Recent things that changed how I work:

  • An untested backup is not a backup. The restore drill in the backup lab is logged for a reason — the first one I ran didn't work.
  • The ticket is the deliverable. Fixing it is half the job; the other half is a note the next person can actually use. The helpdesk lab has five worked tickets and the KB article each one produced.
  • Give out the smallest permission that works. The AD lab delegates password resets to a helpdesk group and nothing else — the boundary I'd be working inside on day one.
  • Write it down while it hurts. Every runbook here exists because I'd already had to rediscover the same fix twice.
